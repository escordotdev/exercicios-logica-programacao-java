# Exercícios de Lógica de Programação em Java

Este repositório reúne meus exercícios e estudos de lógica de programação utilizando a linguagem Java.

O objetivo é praticar os conceitos fundamentais da programação, desenvolver o raciocínio lógico e acompanhar minha evolução como desenvolvedor.

## 📚 Organização dos exercícios

| Pasta | Conteúdo |
|---|---|
| `01-variaveis-e-operadores` | Variáveis, tipos de dados e operadores |
| `02-estruturas-condicionais` | if, else, switch |
| `03-estruturas-de-repeticao` | for, while, do-while |
| `04-vetores-e-matrizes` | Arrays e matrizes |
| `05-metodos` | Criação e utilização de métodos |
| `06-orientacao-a-objetos` | Classes, objetos e conceitos de POO |

## 💻 Tecnologias utilizadas

- Java
- IntelliJ IDEA
- Git
- GitHub

## 📈 Progresso

Este repositório será atualizado continuamente conforme eu avançar nos estudos e resolver novos exercícios.

Construir uma base sólida em lógica de programação e Java, registrando minha evolução por meio de exercícios práticos.
